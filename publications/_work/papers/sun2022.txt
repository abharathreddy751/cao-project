Abstract
Task scheduling and load balancing problem of heteroge-
neous computing environment (HCE) is getting more and
more attention these days and has become a research
hotspot in this field. The task scheduling and load
balancing problem of heterogeneous environment, which
refers to assigning a set of tasks to a specific set of
machines with different hardware and different computing
performance with the goal of minimizing task processing
time and keeping load balance among machines, has been
proved to be an NP‐complete problem. The development
of artificial intelligence provides new ideas to solve this
problem. In this paper, we propose a novel task scheduling
and load balancing method based on optimized deep
reinforcement learning in HCE. First, we formulate task
scheduling problem as a Markov decision process and
then adopt a dueling double deep Q‐learning network to
search the optimal task allocation solution. Then we use
two well‐known large‐scale cluster data sets Google Cloud
Jobs data set and Alibaba Cluster Trace data set to validate
our
approach.
The
experimental
results
show
that
compared with other existing solutions, our proposed
method can achieve much shorter task response time and
better load balancing effect.

INTRODUCTION
Heterogeneous computing environment (HCE) refers to an environment that consists of
interconnected sets of dissimilar hardware or software systems.1 Figure 1 shows the task
scheduling problem in a cross‐domain HCE. In a typical HCE with a central server, all
heterogeneous computers are connected by a central dispatching server which is responsible for
receiving messages from machine nodes and distributing messages to machine nodes. And in
the task scheduling problem of HCE, the task scheduler will collect hardware configuration
information of all machine nodes and assign tasks committed by the central server to these
machine nodes using the information collected according to specific task assignment strategies.
Due to the complexity of task scheduling in cross‐domain HCE, there are multifaceted
problems that have not yet been solved well. First, although modern computer technology
develops quite fast and the computing performance of modern computers is increasingly
higher, there are still huge differences in the computational power of machines in cross‐domain
HCE. So the diversity of computational power should be taken into consideration in task
scheduling problem. Second, the goal of task scheduling is to minimize the task response time.
Task response time is generally calculated as the sum of task WT and task processing time. But
in cross‐domain HCE, for a particular task, its response time is affected by multiple factors at
the same time. On the one hand, a specific task can get different task processing times when it
is assigned to a machine of different computational power. On the other hand, even on the

However, task scheduling problem with resource constraints in HCE has been proven to be
NP‐complete.2–4 Hence the task scheduling problem in cross‐domain HCE is still faced with
great challenges.
To cope with the challenges introduced above, a well‐designed efficient task scheduling
method should be proposed. Generally, the goal of task scheduling is to assign a set of tasks to
the most suitable machines while meeting specific resource constraints as far as possible. As
task scheduling problem with resource constraints is NP‐complete, it is usually solved with
metaheuristic algorithms. But metaheuristic algorithm cannot guarantee the global optimal
solution and its performance is unstable.5 With the rise of artificial intelligence technology,
many researchers began to apply machine learning methods to task scheduling problems.6–8
However, these machine learning‐based methods are heavily dependent on training data sets,
and in most cases such data sets cannot be obtained in advance. Some papers point out to use
Q‐learning method of reinforcement learning (RL) to deal with task scheduling problem,9–12
which avoids the difficulty of obtaining data sets in traditional model‐based machine learning
methods. Nevertheless, due to the size limitation of the Q‐table, the Q‐learning method can
only handle small‐scale task scheduling problems. In addition, most methods are unable to
minimize task execution time while ensuring load balance among machines.
Therefore, this paper put forward a novel task scheduling algorithm based on deep
reinforcement learning (DRL) to address those problems mentioned above. In this paper, we
formulate the task scheduling problem as a Markov decision process (MDP), and then employ
an optimized deep Q‐network to search for the optimal task assignment solution. This method
can directly learn from its past experience without any prior data provided. In detail, the input
of deep neural network is the agent state which is defined as a specific task sequence, and the
output of the network is the final state which represents the optimal task allocation strategy.
When the agent chooses an action for the next state, an elaborately designed reward function
will be used to accelerate the convergence of the learning process. In the experiments setup
stage, we adopt two well‐known large‐scale cluster data sets Google Cloud Jobs Data set (GoCJ)
and Alibaba Cluster Trace data set in our simulation environment to validate our approach in
real workload scenarios. Through the analysis of experimental results, our proposed task
scheduling algorithm outperforms other task scheduling algorithms in terms of average task
response time and average machine central processing unit (CPU) utilization STD.
The major contributions of this paper are concluded as follows:
1. We formulate the task scheduling problem as an MDP so that we can apply the RL method
to it. Furthermore, we give the definition of quadruple (S, A, R, S') of the MDP model.
2. We propose a novel DRL‐based task scheduler named Dueling Double DQN‐based Task
Scheduler (DDDQN‐TS) to address the task scheduling problem of HCE, which improves
the original deep Q‐network (DQN) with double Q‐learning algorithms, dueling network
architectures, target networks, and experience replay techniques.
3. We meticulously design the reward function to realize multiobjective optimization by taking task
execution time and average standard deviation of CPU utilization of machines into consideration.
4. We evaluate our proposed method on two publicly published data sets GoCJ and Alibaba
Cluster Trace data set to simulate real‐world workload scenarios, and compared the
performance of the proposed method with several baselines, showing that it outperforms
other algorithms.

BACKGROUND AND RELATED WORKS
Generally speaking, the goal of task scheduling in HCE is to map tasks to machines with
heterogeneity and order their execution, so as to meet some performance and resource
requirements, including minimizing total tasks execution time, achieving load balancing, and
other user‐specified constraints. As we all know, the heterogeneous task scheduling problem
with resource constraints has been proven to be a nondeterministic polynomial hard complete
problem. Hence, a lot of research work has been done to pursue a relatively optimal result.
Research on this issue in the literature is mainly carried out from the following aspects.
2.1
|
Metaheuristic algorithms
In general, it will take extremely long to obtain the global optimal result of task scheduling problem
through exact methods. Compared with exact methods, metaheuristic algorithms aim to explore
search space and find near‐optimal solutions, which makes them more efficient than exact algorithms
in solving optimization problems in practical application scenarios.5,13,14 Akbari et al.15 presented a
genetic‐base algorithm to address task scheduling problem in HCE which improves task scheduling
efficiency and reduces task execution time. Dordaie and Navimipour16 put forward a hybrid particle
swarm optimization (PSO) method integrating a heuristic hill climbing algorithm. Zhou et al.17
proposed a method named modified genetic algorithm combined with greedy strategy that integrates
a modified genetic algorithm (GA) with greedy strategy, which can reduce the number of iterations to
find an optimal solution. On the basis of small position value rule, Guo et al.18 designed a
PSO algorithm to minimize the execution cost. Xue et al.19 proposed a load balancing optimization
algorithm named ant colony optimization load balancing (ACO‐LB) which is based on ant colony
algorithm so as to solve the VM load imbalance in cloud environment. However, the performance of
these metaheuristic‐based task scheduling algorithms is unstable and possibly trapped into local
optimal solution.
2.2
|
Model‐based machine learning algorithms
In recent years with the rapid development of artificial intelligence technology, machine
learning methods are gradually being applied to task scheduling problems.6–8,20,21 Xie et al.6
employed MultiLogistic Regression theory (called MLRS for short) on task scheduling issue in
HCE, the model of which is trained using the data collected from historical best scheduling
plans. Besides research work using traditional machine learning methods, there are also some
studies done using neural networks. To improve scheduling efficiency, the work of Nemirovsky

2.3

Traditional RL‐based methods
As an important branch of machine learning, RL gets rid of the dependence of historical prior
data compared with model‐based machine learning algorithms because of its ability to self‐
learn in the environment. Studies on task scheduling using traditional RL represented by Q‐
learning algorithm have been carried out these years.9–11,22,23 Orhean et al.10 proposed an RL‐
based task assignment scheme which is implemented by Q‐learning and state‐action‐reward‐
state‐action (SARSA) for scheduling problem of heterogeneous distributed systems by taking
the heterogeneity of nodes and their features within the grid. Peng et al.9 designed a novel task
scheduling method based on Q‐learning algorithm of RL as well as queuing theory to optimize
scheduling efficiency under the resource constraints. Tong et al.11 proposed a new method
named QL‐HEFT which combines Q‐learning algorithm with the heterogeneous earliest finish
time (HEFT) method to minimize the makespan, where the reward function of the origin Q‐
learning algorithm was improved by using the upward rank value of HEFT. Hajoui et al.
proposed an approach that combines Q‐learning by using metaheuristic algorithm ACO with
the mobile agent's systems to reduce the makespan on heterogeneous distributed architectures.
However, all the above Q‐learning‐based task scheduling methods have some common issues.
On the one hand, when the number of tasks and machines is large, the Q‐table used to update
Q‐value will be extremely large, which will lead to an excessive convergence time. On the other
hand, even the problem of slow convergence time is solved with the blessing of high‐
performance modern computers, the extremely huge Q‐table will take up a lot of memory and
eventually result in memory exhaustion.
2.4
|

Recent advances in DRL techniques have opened a new avenue in the field of task scheduling
problems. Since there is no need to maintain a Q‐table data structure as the traditional Q‐learning
algorithm does, DRL algorithm addresses the slow convergence problem and memory explosion
problem when search space is large of traditional Q‐learning by predicting Q‐value using a deep
neural network instead of Q‐table.24 Hence, many task scheduling approaches based on DRL were
put forward.25–29 In Sheng et al.,25 a DRL‐based task scheduling algorithm was proposed to solve both
resource allocation and task scheduling, where a fully connected neural network is used to extract the
features. Rjoub et al.26 put forward four deep and RL‐based task scheduling approaches to automate

Architecture description
Our proposed architecture model is illustrated in Figure 2. As is shown in the figure, the whole
task scheduling framework is composed of three layers:
1. Layer 1: Task submission layer. In this layer, the users of our task scheduling model will
submit their tasks to the central dispatching server. Before their submissions, the attributes
of the tasks (such as MI, CPU utilization, task size, etc.) are supposed to be determined.
2. Layer 2: Scheduling layer. This layer mainly consists of one central dispatching server and
the task scheduler employed on it. The central dispatching server is responsible for
committing all the information needed by the task scheduler and dispatching tasks to
machines according to the scheduling solution generated by the task scheduling algorithm.
3. Layer 3: Execution layer. What execution layer does is to provide the required status
information of machines to the scheduling layer and to execute the tasks issued by the
scheduling layer.

DDDQN‐BASED TASK SCHEDULER IN HCE
Task scheduler is a controller of tasks assignment and resource allocation. An excellent task
scheduler can not only shorten the task execution time and reduce resource consumption but
also balance the load of the system and make full use of the available resources of the system.
Hence, designing an appropriate task scheduler is a crucial issue for HCE.
In this section, we will first introduce the theoretical background and then present our
proposed DRL‐based task scheduler in detail. The contents of this section are organized as
follows. In Section 4.1, we present an overview of MDP, and then we model the task scheduling
problem as MDP. In Section 4.2, we first introduce the theories of Double Q‐learning and
dueling network architectures, and then we illustrate our proposed DDDQN‐TS algorithm in
great detail and display the architecture of our algorithm with some figures.

|

4.2

DDDQN‐TS
Since we have formalized task scheduling problem as MDP, then we can employ deep
Q‐network on it to achieve our optimization goal. As we all know, basic RL methods like
Q‐learning cannot tackle large‐scale state space and action space problem because of the
bloated Q‐table. In this case, DQN is put forward as a new algorithm that combines RL with
deep neural network to address these issues.24,39 DQN enables the RL agents to learn multiple
skills autonomously and realizes end‐to‐end learning. In DQN a deep neural network is used to
automatically learn the characteristics of input data and apply RL method to make decisions
through these learned features.

However, the work of Hasselt et al.34 confirmed that overestimations of Q‐learning are actually a
common problem in practice, and the estimation error will increase with the increase of the number
of actions. The reason for overestimations is the maximum step over estimated action values in
Equation (16), which tends to choose the overestimated Q‐values instead of underestimated Q‐values.
If the overestimations are uniform, the optimal action will not be affected after the maximum step.
But if the overestimations are nonuniform, the overestimated Q‐value of a suboptimal action will
exceed the Q‐value of the optimal action so that the optimal solution cannot be found. To reduce
overestimations in DQN, Double DQN employs the Double Q‐learning method in DQN by
decomposing the max operation in Qtarget into two operations: action selection and action evaluation.
Concretely, while in DQN Qtarget is calculated merely according to the target network, Double DQN
evaluates the greedy policy using the online network and estimates its value using the target network.

5.3.1

Classic methods
1. Round‐Robin (RR): One of the most frequently used load balancing methods is RR. With the
RR method, all the machines are of equal prioritization and pushed into a circular queue. All

the tasks are assigned in an RR fashion by cycling through the circular queue, generally
from head to tail. In such way each machine will get an opportunity to execute a task.
2. Random: Random method is another classic load balancing method. For each task, the
Random method will select one machine randomly to execute this task. It can be known
from probability theory that as the amount of tasks increases, the effect of the Random
method will get close to the RR method.
5.3.2
|
Metaheuristic methods
1. GA: GA is a popular metaheuristic method which is widely used on task scheduling
problems. GA is an efficient global search method which draws lessons from Darwin's
theory of evolution and Mendel's theory of heredity and is able to automatically acquire and
accumulate knowledge about the search space in the search process and adaptively control
the search process to obtain the optimal solution.
2. ACO: ACO is a kind of swarm intelligence algorithm. It was inspired by the foraging
behavior of ants. In nature, during the foraging process of ants, the ant colony can always
find an optimal path from the ant nest and food source. ACO provides a new possibility for
solving complex problems like NP problems.
5.3.3
|
Traditional RL methods
1. Q‐learning: Among many of the traditional RL methods, Q‐learning is one of the most well‐
known value‐based methods. As is illustrated in Section 4.1, RL methods are based on MDP,
so the goal of Q‐learning is to find the best action‐selection strategy and maximize the
immediate reward obtained in a specified environment.
2. SARSA: Similar to Q‐learning method, SARSA is also an algorithm based on MDP. What
distinguishes SARSA from Q‐learning is the Q‐value update rule. Q‐learning used the greedy
rule to learn the Q‐value, while SARSA used the action performed by the current policy to
learn the Q‐value.

Moreover, through Figure 12B and Table 6, we can conclude that on GoCJ data set DRL‐
based methods surpass most non‐DRL‐based methods in terms of STD. Because for a certain
scheduling strategy, task execution efficiency and load balancing effect are often related. DRL‐
based methods have much faster task response time, so they also have lower STD of machines.
In our proposed method, we elaborately design the reward function so that the DRL agent
chooses the action which will minimize the task response time and machine STD
simultaneously and finally find the optimal task scheduling solution. Considering the STD
metric, our proposed method DDDQN‐TS improved the load balancing performance by 11%
compared with the suboptimal and 27% compared with the worst.

machine STD simultaneously. This is why the load balancing effect of DDDQN‐TS is much
better than other baseline algorithms according to Figures 10B,C and 12B,C.

Algorithm 3 to accelerate the convergence of the learning process and find better task

CONCLUSION AND FUTURE WORK
Doing efficient task scheduling without sacrificing the load balancing effect is a challenging
problem in an HCE which contains diverse computational resources. To address this problem, in
this paper we propose a novel task scheduling framework which is composed of task submission
layer, scheduling layer, and execution layer. In the scheduling layer, we first formulate static task
scheduling problem as an MDP and then design a DRL‐based task scheduling algorithm named
DDDQN‐TS to dispatch massive tasks to appropriate machines in HCE under resource constraints.
Furthermore, to comprehensively evaluate the performance of our proposed method, we compare
the performance of our proposed method with multiple baselines on two real‐world data‐based data
sets. And the experiment results show that our proposed method outperforms the baselines in
terms of average task response time and average standard variation of machine CPU utilization,
which represents higher task scheduling efficiency and better load balancing effect.
According to our previous findings, several inspired future research works are concluded as
follows. First, we aim to extend our task scheduling network architecture to dynamical
workloads and high concurrency scenarios. In such case, the algorithm needs to be further
adjusted to adapt to workloads of different intensities. Additionally, we can optimize our
scheduling model using multiagents and voting mechanisms to find more robust and stable
scheduling solutions. Finally, we can also migrate our proposed network structure to other
computing environments, such as cloud computing environments to deal with cloud job
scheduling problems.
