A B S T R A C T
Efficient job scheduling for heterogeneous computing environments has attracted widespread
attention, jobs are usually modeled as directed acyclic graphs(DAG). Optimizing scheduling can
improve system throughput. We propose a two-stage scheduling algorithm, which calculates task
selection and processor allocation respectively. In task selection stage, we utilize a bidirectional
graph convolution network to learn DAG structural features, and a fully-connected network to
generate proper scheduling scheme. In the processor allocation stage, we propose a heuristic
based on optimistic cost table(OCT) and task duplication, which trade-off scheduling allocation
better. Experiments of various scheduling scenarios have been conducted, and the results
show that the proposed algorithm has better scheduling performance than the compared
heterogeneous DAG scheduling algorithms.
1. Introduction
With the improvement of application scale and modularity, more and more applications have put forward requirements for the
heterogeneity of computing resources, such as deep neural network training, graphics and image modeling, etc., which have different
requirements for CPU, GPU and other computing resources. Therefore, in order to better serve these applications, more and more
heterogeneous computing platforms appear in modern computer design, and the related technologies are also developing.
Heterogeneous computing platforms provide computing services based on a group of heterogeneous processors. There are a
certain number of jobs running on them. The scheduler is responsible for allocating processor resources to ready jobs, and the
completion efficiency of these jobs mainly depends on the quality of the scheduling algorithm. Therefore, it is very important
to optimize the job scheduling strategy for heterogeneous platforms. Specifically, the optimization goal of job scheduling in
heterogeneous environments is to improve performance indicators such as job completion time, acceleration ratio, throughput and
response time.
At present, a large number of scholars have carried out in-depth research on job scheduling in such heterogeneous environments.
A submitted job can usually be formalized as a Directed Acyclic Graph(DAG). Nodes in the graph represent a process in the job,
and edges represent the existence of certain dependencies, such as data communication. For heterogeneous processors, the cost of
executing tasks on different processors is different. The goal of scheduling is to allocate the task nodes in each job to the appropriate
processor resources in order to optimize the average task completion time of the system.
In addition, according to whether the job information can be obtained in advance, the problem can be divided into the following
two categories: static job scheduling and dynamic job scheduling. Static job scheduling, also known as offline scheduling, means

Static DAG scheduling based on heterogeneous systems has been proved to be a NP complete type problem [ ]. Algorithms can be
1
divided into two categories: algorithms based on artificial heuristics and algorithms based on neural networks. Among them, heuristic
based scheduling algorithms can be further divided into deterministic scheduling and non-deterministic scheduling according to
whether the scheduling strategy is determined. The deterministic algorithm generates the same scheduling result for the same DAG
input every time, and the performance of such heuristic is poor due to fixed rules.
The basic idea of non deterministic scheduling algorithm is to give an approximate solution to the problem from plenty of
feasible solution. The algorithm needs to constantly evaluate the quality of the current solution and optimize it in the iteration [ ].
2
Therefore, although this kind of algorithm can often give better solutions, it introduces a large amount of execution time overhead.
The above algorithms have been widely used in the single job (DAG) scheduling problem, while the real production environment
is mostly a multi-workflow environment, and there are multiple ready jobs in the system at the same time [ ], which will be a large
3
decision space in each scheduling, and it is difficult for heuristic rules to make full use of environmental information for decision-
making. The neural network constructed using multiple fully-connected layers has the ability to fit complex functions. Thus, many
proposed works attempt to learn task scheduling strategies using deep neural network, efficiently boost the overall performance
over existing heuristics.
In This paper, we propose a DAG scheduling algorithm in heterogeneous environments based on neural network learning model.
The algorithm extracts DAG graph features according to the graph convolution network(GCN), learn from feature representations
and gives node selection, then implements the task allocation of the determined nodes based on the heuristic algorithm. When
learning DAG features, we further strengthen GCN by introducing message passing from parent node to child node, we use the
Proximal Policy Optimization (PPO) [ , ] to train the neural network model for optimizing scheduling policy. In the processor
4 5
allocation stage, we propose a heuristic algorithm combining optimistic cost table and critical parent task duplication, which can
effectively reduce the idle time of the processor and improve the overall scheduling performance. To sum up, this paper proposes
a scheduling model for heterogeneous processors and multi-DAGs job environments, and its contributions can be summarized as
follows:
1. In the DAG job feature extraction stage, a GCN network based on bidirectional message passing mode is proposed to learn
the overall DAG structure.
2. In the training stage, the neural network is trained by using PPO based on importance sampling, and appropriate reward
function are set to effectively improve the training efficiency.
3. In the processor allocation stage, a hybrid allocation strategy based on optimistic cost table and critical parent node
duplication is proposed to improve the overall scheduling performance.

4. Proposed method
The detailed process of the algorithm proposed in this paper is shown in
, which is mainly composed of three parts:
Fig. 1
graph convolution network, policy network and heuristic scheduling algorithm. The scheduling process of the algorithm is generally
divided into three stages: the feature extraction stage of job DAGs, the node selection stage and the processor allocation stage. In the
node selection stage, the original features of the task nodes will be sent to the GCN network, which can effectively learn the DAG
structural features and output them as high-level representations of the task nodes; After that, the high-level representations will be
directly sent to the policy network, which will select node to schedule; Finally, the algorithm schedules the output nodes of the policy
network to the most suitable processor core according to the proposed improved heuristic allocation algorithm. Repeat the above
process until all nodes in the current system have been allocated to the appropriate processors. The algorithm constantly learns and
updates its own strategies in the environment, The introduction of heuristic algorithm helps to improve the decision-making speed
and overall scheduling performance of the algorithm when selecting processors.
4.1. Bidirectional feature extraction based on graph convolution network
The algorithm we propose makes decisions according to the comprehensive information of jobs in the system and generates
a reasonable scheduling scheme. In the multi-job system environment, the number of jobs is always changing dynamically, and
there will be jobs completed or arrived at a specific time. Therefore, the scale of the input feature is changing dynamically, and
the network needs to have the ability to process the input information effectively. Therefore, for the input of the original DAGs
(including the information of each node’s execution cost, communication cost, out/in degree, number of nodes to be scheduled,
etc.), the graph convolution network is introduced to learn its high-level feature representation, so as to obtain the scalable task
state information in the system, which is helpful for the policy network to make decisions on the next task node.

data. Graph convolutional neural networks [

4.3. Processor allocation based on hybrid heuristic strategy
After the task node is selected, it needs to be allocated to processor to ensure better overall performance. If the processor need
to select together with node, so the decision space of the algorithm is the product of the number of nodes to be scheduled and
the number of processors, which will become very large, affecting the efficiency of the algorithm. Therefore, this paper will use
heuristic algorithm in the processor allocation stage, fully decoupling the two links of task selection and allocation. In the node
selection stage, only the input characteristics are concerned, and the processor information is ignored. In the processor allocation
stage, only the processor information is concerned.
Three types of heuristic algorithms have been analyzed in the previous text. Most of list based heuristics are based on the idea of
the earliest completion time, which takes poor performance; Clustering based algorithms need to consider the overall information of
the DAG. Tasks in the same clusters often need to be assigned to the same processor, and generally have a high time complexity, so
the algorithm is difficult to apply here; The idea of task duplication can be applied to the processor allocation phase to make full use
of idle time [
]. Many duplication based algorithms try to duplicate all parent nodes. This will cause the duplication of multiple
23
parent task nodes. Although it can greatly reduce the idle time of the processor, it will introduce a large number of redundant
executions, which may not necessarily improve the final scheduling performance. In [

However, duplication based policy usually tends to copy the task to processor to advance the completion time of the current node
as much as possible. This method only considers the impact of scheduling the current node, but ignores the impact of the current
scheduling choice on subsequent nodes, which will affect the overall scheduling performance. Therefore, it is necessary to quantify
and balance the impact of current scheduling decisions on future scheduling costs. The optimistic cost table(OCT) has been proved
to be a very effective ‘‘Look-ahead’’ idea. When allocating processors, the minimum value of the sum of the earliest completion time
and optimistic cost estimate is considered as the optimal solution to allocate tasks to the corresponding processor. By estimating the

6. Conclusion
This paper proposes a DAG job scheduling algorithm based on graph convolutional network and reinforcement learning. By
learning the characteristics of job DAGs based on bidirectional message passing GCN network, the representations of node level,
DAG level and global level are obtained, and input into the multi-layer fully connected network to select task node. In the task
allocation phase, a heuristic algorithm named DPEFT based on critical parent task duplication and optimistic cost table is proposed.
Network are trained based on PPO. The experimental results show that compared with other classical scheduling algorithms, this
algorithm has better scheduling performance, which improved the average job cost, parallel performance, stability, etc.
The algorithm proposed in this paper is suitable for DAG application scheduling with arbitrary structure. The benchmark dataset
is relatively comprehensive, but lack of specialization; Moreover, our algorithm only considered the optimization of the average
completion time of DAG jobs, without considering optimizing other indicators such as energy cost or response time, etc; In addition,
this paper assumes that jobs have equal status and occupy processors fairly, and does not consider the situation where jobs have
different priorities, which will be considered in the future work.
Task selection and processor allocation are two important stages of the implementation of this algorithm. Compared with the
traditional DAG scheduling algorithm, the selection order of nodes is determined by the neural network and is no longer based on
manually defined priority indicators. Therefore, in the future work, we can consider further optimizing the mechanism of graph
convolution network to enhance the ability of the model to express the structure of DAGs. In addition, the heuristic algorithm with
fixed rules limits the exploration of policy learning, so we can consider building a task allocation algorithm based on reinforcement
learning to enhance the exploration of the model through multi-agent learning.
