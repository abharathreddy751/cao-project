##### SHEET Project_Summary 11x2
Project Title | AI-Assisted Heterogeneous Computing Framework for Dynamic Task Offloading and Scheduling
Base Work | US 11,561,826 B1 – Scheduling Processing of Machine Learning Tasks on Heterogeneous Compute Circuits
Core Idea | Use a task graph for dependencies, continuously monitor heterogeneous resources, use a lightweight ML model to recommend a resource, dynamically offload the task, execute independent tasks in parallel, and collect performance feedback.
Primary Prototype | Raspberry Pi + laptop/desktop; optional NVIDIA GPU or Jetson
Initial ML Options | Decision Tree or Random Forest
Main Inputs | CPU utilization, memory utilization, GPU utilization where available, queue length, task type, task size, network latency, historical execution time
Main Output | Recommended execution resource: Raspberry Pi, laptop CPU, GPU/Jetson
Workloads | Matrix multiplication, image processing, sorting, AI inference, compression
Comparisons | Sequential execution, static allocation, round-robin scheduling, proposed AI-assisted dynamic scheduling
Metrics | Execution time, speedup, throughput, resource utilization, network/offloading overhead, scalability
Important Reporting Rule | No assumed numerical project results. Final graphs will use measured experimental results.
