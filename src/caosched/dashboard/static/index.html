CAO · Prediction-aware DAG scheduling on heterogeneous cores

Base framework demonstration on one laptop (Intel Core i5-1235U, 2 P-cores + 8 E-cores). Every number on these screens is read from event logs, artifacts or verified result files.

HISTORICAL REPLAY

The runtime places a coordinator, local P-core and E-core worker pools and one remote worker on this machine. The remote worker is simulated: a node process on a local E-core behind a configurable link shim. No Raspberry Pi or NVIDIA T4 is connected.

Remote worker R0 SIMULATED

A local node process pinned to an E-core, reached through the lan_1g link shim (software-injected latency and bandwidth). It exercises the real remote code path but is the same silicon as the local E-cores.

Raspberry Pi NOT CONNECTED

Planned remote pool R_PI. Node code is portable and the connect-to-host path is implemented, but it has not been run or validated on a Pi.

No device metrics: nothing is attached, so none are shown.

NVIDIA T4 NOT CONNECTED

Planned remote pool R_T4 with the CUDA img_edges variant. The variant is implemented but never executed: there is no GPU or PyTorch on this machine.

No GPU utilisation or device metrics: nothing is attached, so none are shown.
